# CDC Sync Engine Dashboard (Frontend)

This is a lightweight, high-performance monitoring dashboard for the CDC Sync Engine, built with **Vue 3** and **Vite**.

## Features

- **Real-time Synchronization Monitoring:** Visualize the data flow from PostgreSQL to Elasticsearch.
- **System Health Overview:** Monitor the status of the CDC pipeline.
- **Event Auditing:** View the most recent events captured by Debezium.

## Tech Stack

- **Framework:** Vue 3 (Composition API)
- **Build Tool:** Vite
- **Styling:** Vanilla CSS / Tailwind (if configured)
- **API Communication:** Axios

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
